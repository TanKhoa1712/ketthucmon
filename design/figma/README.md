# KShop Figma concept

`kshop-ui-concept.svg` is a vector UI concept board for Step 7. It contains six desktop artboards:

1. Storefront and product discovery
2. Login and registration states
3. Checkout with COD and VNPay choices
4. Customer order history
5. Admin product and category management
6. Admin order management

Figma Design file: [KShop - UX UI Concept Step 7](https://www.figma.com/design/d5XyiIzqGT7mXma6Y1slbf/KShop---UX-UI-Concept-Step-7)

## Open in Figma

1. Create or open a Figma Design file.
2. Use **File → Place image...** (or `Ctrl+Shift+K`) and select `kshop-ui-concept.svg`.
3. Click the canvas to place the board, then zoom to fit.
4. The artboards are grouped as vector content. Ungroup a screen to edit its individual shapes and text, or create Figma frames around each artboard.

The board follows the existing storefront palette and Vietnamese product/order flows. It is a static design draft, not a replacement for the React implementation.
